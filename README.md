# Dependency Graph Visualizer (Вариант 28)

## Общее описание
CLI-утилита для визуализации графа зависимостей пакетов формата Java (Maven).
Разрабатывается в рамках дисциплины «Конфигурационное управление». Проект разбит на этапы, описание которых приведено ниже.

## Сборка и запуск
*   **Сборка проекта:** `.\gradlew build`
*   **Запуск приложения:** `.\run.bat [опции]`

---

## Этап 1. Минимальный прототип с конфигурацией
**Описание:**
Приложение считывает параметры из командной строки, валидирует их и выводит в формате «ключ-значение». Реализована обработка ошибок для всех параметров.

**Поддерживаемые опции:**
*   `-p <package_name>` — Имя анализируемого пакета (обязательный).
*   `-r <url_or_path>` — URL-адрес репозитория или путь к файлу тестового репозитория (обязательный).
*   `-d <number>` — Максимальная глубина анализа зависимостей (обязательный, целое число > 0).
*   `-t` — Флаг включения режима тестирования (опциональный).

**Примеры использования:**
```bat
# Успешный запуск
.\run.bat -p org.apache.commons -r https://repo.maven.apache.org/maven2 -d 3

# Обработка ошибки (неверный тип данных)
.\run.bat -p test -r url -d abc
```
